Projeto focado em análise exploratória de dados e criação de dashboards para geração de insights estratégicos.

## Tecnologias utilizadas
- Python
- Pandas

## Funcionalidades
- Limpeza e tratamento de dados
- Análise exploratória
- Visualização de dados
- Geração de insights

## Objetivo
Transformar dados em informações úteis para tomada de decisão.
